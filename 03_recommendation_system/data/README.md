## 📊 Fonte e Cobertura do Dataset | Dataset Source and Time Coverage

### Português

O dataset utilizado neste projeto foi obtido a partir do portal oficial de dados abertos da CEAPS (Cota para Exercício da Atividade Parlamentar dos Senadores), disponibilizado pelo Senado Federal do Brasil.

Para esta análise, foram utilizados dados referentes aos anos de **2024, 2025 e 2026**, com o objetivo de garantir uma representação mais recente e relevante das despesas parlamentares.

O conjunto de dados contém registros detalhados das despesas dos senadores, incluindo viagens, manutenção de escritório, combustível, hospedagem e outras despesas administrativas. Esses dados foram posteriormente tratados, limpos e agregados para viabilizar a construção do sistema de recomendação.

---

### English

The dataset used in this project was obtained from the official CEAPS (Quota for Exercising Parliamentary Activity of Senators) open data portal provided by the Brazilian Federal Senate.

For this analysis, data from the years **2024, 2025, and 2026** was used in order to ensure a more recent and relevant representation of parliamentary expenditures.

The dataset includes detailed records of senators' expenses, such as travel, office maintenance, fuel, accommodation, and other administrative costs. This data was later cleaned, processed, and aggregated to enable the development of the recommendation system.
